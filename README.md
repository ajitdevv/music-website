🎶 Music Website
A **fully functional and responsive music web app** built with **HTML, CSS, and Vanilla JavaScript**, featuring modern UI/UX and interactive audio playback.**
---
 🚀 Live Demo
[Click here to view the live site](https://ajitdevv.github.io/music-website/)


✨ Key Features

| 🎧 Audio Player |Play, Pause, Seek, Progress Bar, Current Time |
| 💖 Favorites | Saved using LocalStorage |
| 🌙 Dark/Light Theme | Smooth CSS transition |
| 🔍 Live Search | Search by song title or artist |
| 📱 Responsive Layout | Mobile, tablet, desktop friendly |
| 🖼️ Song Categories | Organized song sections |
| 🧭 Now Playing Bar | Persistent playback across pages |
| ⬆️ Back to Top Button  | Can be added for long playlists |



🛠️ Tech Stack
-**HTML5** – Semantic structure  
- **CSS3 + Media Queries** – Responsive and adaptive layouts  
- **JavaScript (Vanilla)** – Interactivity, audio controls, favorites, search  
- **LocalStorage API** – Persistent data storage  
- **GitHub Pages** – Hosting  


📄 Project Highlights
- Fully **responsive** music web app  
- Interactive **audio player** with progress bar and timer  
- Persistent **favorites** using LocalStorage  
- Smooth **theme toggle** (dark/light)  
- **Searchable and categorized library** for easy browsing  
- Optimized for **mobile, tablet, and desktop devices**
